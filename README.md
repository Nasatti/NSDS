## Course Overview

This repository contains study notes, laboratory implementations, and evaluation lab projects for the graduate course **Networked Software for Distributed Systems (NSDS)** at Politecnico di Milano.

The course investigates modern paradigms, architectural abstractions, and programming models for distributed computing infrastructures spanning the entire cloud-to-edge continuum.

---

## Laboratory Modules

Each module folder contains its own dedicated `README.md` with specific exercise details, architectures, and evaluation projects:

1. **Module 1: Actor Model & Distributed Concurrency (Akka)**
2. **Module 2: Distributed Message Queues & Event Streaming (Apache Kafka)**
3. **Module 3: Flow-Based & Edge Computing (Node-RED)**
4. **Module 4: Large-Scale Data Analytics (Apache Spark)**
5. **Module 5: High-Performance Parallel Computing (MPI)**
6. **Module 6: Embedded Systems & IoT (Contiki-NG)**
